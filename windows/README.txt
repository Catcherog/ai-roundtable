AI 圆桌 · AI Roundtable 4.0.1 for Windows x64

解压整个 ZIP，进入 AI-Roundtable 文件夹，双击 AI-Roundtable.exe。请保留所有同级文件夹。
本包内置 Python 和 .NET。桌面界面需要 Microsoft Edge WebView2 Evergreen Runtime。
下载运行时：https://developer.microsoft.com/microsoft-edge/webview2/
在终端安装并登录至少一个可用的模型 CLI（agy、codex 或 grok），然后重新打开 AI 圆桌。
按 Ctrl+, 选择席位、模型和推理档位。「并发实测连通」可检查账号和模型能否响应。
本机会议与设置在 %USERPROFILE%\.ai-roundtable 中。
