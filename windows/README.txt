AI 圆桌 · AI Roundtable 5.5.1 for Windows x64

解压整个 ZIP，进入 AI-Roundtable 文件夹，双击 AI-Roundtable.exe。请保留所有同级文件夹。
本包内置 Python 和 .NET。桌面界面需要 Microsoft Edge WebView2 Evergreen Runtime。
下载运行时：https://developer.microsoft.com/microsoft-edge/webview2/
先在终端确认模型工具（如 Codex 或 Claude Code）能正常回答，再打开圆桌。一个工具就能分饰多席。
按 Ctrl+, 选择席位、模型和推理档位。「并发实测连通」可检查账号和模型能否响应。
本机会议与设置在 %USERPROFILE%\.ai-roundtable 中。
从 4.0.2 升级前请退出程序并备份整个数据目录。新版保存时保留最近 50 场；整场重写时保留最近 500 条发言。删除没有回收站，受管文件合计超过 128 MiB 的目录不能绑定。

Extract the entire ZIP and open AI-Roundtable.exe. Keep the other files and directories beside it.
Python and .NET are included. Install the Microsoft Edge WebView2 Evergreen Runtime if prompted.
Sign in to at least one supported CLI and reopen the app. Press Ctrl+, to select a model and test the connection.
The workbench interface is in Chinese. Project and English guide: https://github.com/Catcherog/ai-roundtable
Upgrading from 4.0.2? Quit the app and back up the entire data directory before opening 5.5.1. See the project guide for history limits and changes to project folder support.
